# projeto-integrador-frontend--savionathannael-
Loja Virtual de produtos 3D
Este projeto tem como tema uma loja virtual de produtos com visualização em 3D.
O objetivo é apresentar um catálogo de produtos onde o usuário pode girar,
ampliar e visualizar os itens em modelos tridimensionais antes da compra,
oferecendo uma experiência de compra mais imersiva do que fotos estáticas.
